## What is counted

For each case, a required span is a declared `(path, exact substring)` pair. A hit requires the complete substring inside **one** exact excerpt from that file; fragments in separate excerpts do not combine. Each authored pair counts once. Required files are the distinct paths in those keys, and a file hit means at least one excerpt of that path, even if its required condition is absent. Maps and the line index do not count as excerpt hits.

The pooled span fraction is `sum(span hits) / sum(required spans)`, with an analogous file fraction. A case passes mechanically only when all its spans and required cutoffs are present and source integrity passes. Duplicate line occurrences are `number of excerpted (path, line) occurrences - number of distinct (path, line) pairs`, summed across cases. Empty packets retain all their required spans and files in the denominator.

## Reproduction

Use clean, pinned checkouts of the two source revisions and the measurement commit above. Substitute their absolute paths below and choose new output paths outside all checkouts. Keep inputs quiescent. Record and compare the source/tool/dataset hashes before and after each arm as described above; the audit alone cannot establish which collector produced a receipt.

```bash
SB_MEASURE=/absolute/measurement-checkout
SB_BEFORE=/absolute/dev32-checkout
SB_AFTER=/absolute/dev35-checkout
SB_RUN=/absolute/new-output-directory
mkdir "$SB_RUN"
python3.12 -I "$SB_MEASURE/benchmarks/source_span_development.py" generate \
  --output "$SB_RUN/dataset"

PYTHONHASHSEED=0 PYTHONPATH="$SB_BEFORE/src" python3.12 -B \
  "$SB_MEASURE/benchmarks/run_task_lab.py" --evidence-only \
  --dataset "$SB_RUN/dataset" --output "$SB_RUN/before.json"
# Expected exit 1: inspect the complete receipt and the retained misses.
PYTHONHASHSEED=0 PYTHONPATH="$SB_AFTER/src" python3.12 -B \
  "$SB_MEASURE/benchmarks/run_task_lab.py" --evidence-only \
  --dataset "$SB_RUN/dataset" --output "$SB_RUN/after.json"
# Expected exit 1: the oversized-anchor case remains a mechanical miss.

python3.12 -I "$SB_MEASURE/benchmarks/source_span_development.py" audit \
  --dataset "$SB_RUN/dataset" --receipt "$SB_RUN/before.json" \
  --output "$SB_RUN/before-audit.json"
python3.12 -I "$SB_MEASURE/benchmarks/source_span_development.py" audit \
  --dataset "$SB_RUN/dataset" --receipt "$SB_RUN/after.json" \
  --output "$SB_RUN/after-audit.json"
```

The generator refuses existing destinations, dangling destination links and output inside its own checkout. The auditor refuses existing outputs and writes inside the dataset or its own checkout. Neither overwrites earlier runs. This auditor accepts only the fixed generated bytes; arbitrary owner datasets continue to use the existing [external evaluation tools](held-out-evaluation.md). Fresh receipts include elapsed times and therefore need not have the same complete-file hash as this run; fixture identities and the stated counts should reproduce.
