Export each pinned head tree to a fresh directory outside the application checkout, without `.git`, symlinks, hard links, special files or execution. Both arms receive the same task, PR text, exact diff, full read-only current source, model/settings and native retrieval. The prepared arm additionally receives the frozen candidate packet. First run a local permissions control and one bounded actual-host retrieval preflight on inert synthetic data; stop if the expected command action is absent or any prohibited action appears. Then run two fresh sessions per arm per case with alternating arm order and a fixed seed. Retain every start, failure, prompt, answer, action and reported usage privately. Source and manifest identities must match before/after every attempt. No automatic retry or candidate adjustment.

After all answers are frozen, open the pinned reference files and compare each claimed finding to the published reference and exact source. Record reference matches, apparent misses, unsupported claims, citations, useful abstention and reviewer disagreements separately. Reference findings can be incomplete or mistaken, so unmatched claims need source review, not automatic false-positive labels. A root-AI mapping is provisional until a separate human reviewer checks it. Two cases and two repetitions are descriptive; timing, token and cost differences cannot qualify the product. The development gate requires no baseline-supported critical finding lost, no new unsupported critical claim, and at least equal supported task outcomes. Independent human grading and a fresh owner-approved private-source trial remain separate future gates.
