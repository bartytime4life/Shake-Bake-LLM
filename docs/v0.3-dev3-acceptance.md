# v0.3.0.dev3 qualification

2026-11-04, Linux/Python 3.12.14 development environment. The program suite passes 72 tests without skips; the packaged copy is checked separately before delivery.

Implemented: `assist` CLI, owner-controlled per-task profile selection, human-readable choice/rejection explanations, global/per-profile disabling and an invocation off switch. Routing requires comparable reviewed held-out records, no recorded critical misses/unsupported critical claims, accuracy at least matching the paired native baseline, and matching model/pipeline identity. Latency is a tie-breaker after recorded accuracy. Owner records are trusted configuration, not authenticated proof of real trials.

HTTP contract checks use a simulated local service. They cover inventory/metadata/source-call ordering, digest checks before source and after response, preserving evidence and discarding notes on identity change, and the absence of service calls when disabled, unqualified or rejected. Policies supplied inside inspected source roots are refused. Malformed records fail closed while preserving available source.

All shipped profiles remain candidates with no evaluation or invented digest. The shipped example returns evidence and `no_qualified_profile`, with final-answer readiness false. A successful synthetic routing test does not qualify any actual model. Ten exposed Task Lab jobs still retain their required spans; their semantic scores remain pending.

The off switch disables new model/inventory calls. It does not terminate a separate Ollama daemon or attest GPU cancellation. Tag metadata checks do not verify loaded weight bytes or prevent all races. Actual Ollama behavior, reviewed model accuracy, hosted baselines, MCP integration, GUI/setup and measured savings remain unverified or unimplemented.
