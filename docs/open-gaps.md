# What still needs proving

Reviewed November 5, 2026 for 0.4.0.dev8. Program tests do not replace the following trials.

[Known Issues](../KNOWN_ISSUES.md) tracks explicit security/reliability qualification gaps and release blockers. The [PC checklist](PC-CHECKLIST.md) contains the corresponding pending gates. These records do not claim a completed independent security audit or newly validated vulnerabilities.

| Gap | Why it matters | Current handling / next evidence |
| --- | --- | --- |
| Real model quality | A confident local mistake can make the host less accurate. | Retained smaller-model, 8B prompt and thinking-budget results are summarized in [evaluation status](evaluation-status.md). Valid JSON and larger output budgets do not establish accurate handoffs. All profiles remain unqualified; a development pass, new reserved-cohort review and paired final-host evaluation remain needed. Original `.dev6` records remain unavailable. |
| Native-host comparison | The native assistant may already do the preparation well. | One actual Codex evidence-only synthetic smoke has scoped evidence in codex-host-handoff.md; broader host behavior remains unqualified. Compare native host, deterministic evidence and model-assisted evidence with identical tasks/source. The separate [host-note diagnostic](host-note-diagnostic-2026-11-05.md) compares final answers from identical captured packets with/without retained local notes. It does not supply a native retrieval arm or full-workflow benefit measurement. |
| Retrieval blind spots | Excerpts can omit the decisive branch. | Exact spans and cutoffs are tested; finite lexical windows remain incomplete. Add unseen cross-file and large-repository tasks. |
| Evaluation contamination | Known questions or repeated cases inflate apparent strength. | External datasets, declared splits, pinned inputs and isolated keys are implemented. A separate AI-authored cohort was evaluated after prompt freeze and is now exposed. Reserve a fresh cohort after any new candidate freeze; separately label AI review and human qualification. The paired final-host study remains needed. |
| Failure accounting | Dropping slow or invalid attempts inflates accuracy. | Checkpoint attempts; failures count in reviewed accuracy. Unknown usage stays unknown. No automatic model substitution or retry. |
| Interrupted or changed runs | Different source/model states may be incomparable. | Freeze plan and identities; stop detected changes; save Ctrl+C results. Hard-crash resume remains unimplemented. |
| Hardware and tuning | A leaderboard does not establish local memory fit or quality after quantization. | Record model/digest and requested settings; do not infer GPU performance. Controlled cold/warm and memory trials remain needed. |
| Per-PC calibration | A good profile on one machine may perform differently on another. | Manual trial/checklist now; automatic tuning, persistent per-device profiles and hardware/runtime identity enforcement are planned in per-pc-calibration.md. |
| Visual/accessibility checks | Working APIs do not establish usable desktop or phone controls. | Historical blocked navigation remains recorded. Later installed in-app readiness and copy-recovery flows, exact 3,392-character native/manual transfer, and source/installed Chromium checks have scoped evidence; see [copy recovery](copy-and-screening-2026-11-05.md). Wider devices and formal assistive-technology qualification remain open. |
| Setup boundaries | Defaults can expose source or imply an unproven model won. | Loopback app, metadata-first checks, explicit roots and unqualified labels. A supported-Python source launcher and persisted service AI choice now exist. Windows, guided source setup and automatic downloads remain pending. |
| Sensitive data | Exact evidence can contain private material. | No automatic cloud client; copy/export is explicit. Owners choose permitted roots. Complete secret detection and daemon network isolation are not provided. |
| Licensing and updates | Terms, candidate tags and benchmark conditions change. | Keep publisher links separate from local results; recheck licenses/tags before shipping downloads. No universal best-model or free-compute claim. |
| Review provenance | An edited review record does not prove correctness. | Policies outside inspected roots; matching records required. Review identity is self-asserted. Authenticated independent promotion remains future work. |

The next useful work is a stronger eligible candidate or preparation task design that survives the exposed quality checks, plus actual-host disconnect/deadline/restart and local-model orchestration, before a frozen unseen paired comparison. Original screening recovery remains optional historical follow-up, not a reason to substitute or relabel new runs. Evidence-only handoff and cancellation of an explicitly stopped owned runner now have actual Codex evidence; they do not replace these gates. Retain new and historical failures. The helper remains preparation for the main assistant's reasoning; no deployment or production-readiness claim follows from these checks.
